# TPN2 - Ejercicios individuales

Carpetas organizadas según los apartados individuales de la guía audiovisual. Los proyectos mantienen una copia local del código de referencia y cada carpeta incluye su video, repositorios fuente y pasos básicos de ejecución.

- `Ejercicio1/`: React + Spring Boot API REST.
- `Ejercicio2/`: React + Spring Boot API REST.
- `Ejercicio3/`: React + Spring Boot API REST.
- `Ejercicio4/`: ejemplos Java de patrones de diseño.
- `Ejercicio5/`: React + Spring Boot con seguridad.

Las carpetas `Backend` y `Frontend` se ejecutan por separado cuando corresponda. Consultá el README de cada ejercicio para requisitos y comandos.
